# 日序 · Daynest

把想做的事，留在每天看得见的地方。

日序是一款 Windows 桌面悬浮日历。它把今日必做、截止任务和长期计划放在同一个窗口里，支持子任务清单、自定义背景、到点提醒，以及只显示当前重点的小条模式。

**本地运行 · 无需账号 · 自动保存 · 单文件安装**

![日序主界面](docs/images/calendar.png)

> 当前版本：**1.5.1**。截图使用示例计划。

## 功能

### 三类计划，各有位置

| 类型 | 适合记录 | 显示与完成规则 |
| --- | --- | --- |
| 今日必做 | 当天要完成的具体事项 | 绑定执行日期，支持每天、工作日或每周重复 |
| 截止任务 | 报告、申请、项目交付 | 持续显示，按截止时间排序，可设置提前提醒 |
| 长期计划 | 学习目标、阅读、持续推进的事情 | 不限截止日期，每天可见，直到完成或归档 |

切换日历日期只切换该日的必做列表，长期计划与截止任务仍然保留。截止倒计时始终按实际时间计算。

### 把大任务拆成小步骤

- 在父任务下点击 **「＋ 添加子任务」**，直接输入步骤。
- 按 `Enter` 连续添加，点击叉号结束输入。
- 子任务可以独立勾选、编辑、删除，并显示完成进度。
- 子任务全部勾选后，仍由你决定何时完成父任务。
- 重复日程的子任务按日期记录完成状态；归档父任务会保留其子任务。

任务的 **「…」** 菜单只保留编辑、归档、删除。左下角显示完成 / 归档总数及今日进度，同一父任务不会因为完成后再归档而重复计数。

![任务菜单](docs/images/task-menu.png)

### 完整日历与任务小条

完整窗口用于查看、安排和整理计划；点击顶部的细条图标，可以收成更小的悬浮卡片。

![任务小条](docs/images/compact.png)

小条显示时钟、日期、星期、一条待办任务，以及截止提示或今日完成进度。优先显示未完成的今日任务，其次是最早截止任务；没有这两类任务时，再从此前未完成、未来日程或长期计划中选择。长标题可以悬停查看完整内容。

展开与收起使用细碎片聚散动画，切换日期使用星光动画；关闭 Windows 动画效果时会直接切换。

### 让它融入桌面

- 自定义 JPG、PNG、BMP 背景，图片会保存为本地副本。
- 调整背景遮罩、窗口透明度和计划字号。
- 浅色、深色或跟随系统外观，支持多种配色。
- 顶部非按钮区域可拖动，支持置顶、位置锁定和窗口缩放。
- 系统托盘、登录自启、显示 / 隐藏快捷键。
- 到点提醒、提前提醒、免打扰，以及提醒延后 10 分钟。

## 安装与启动

适用于 **Windows 10 / 11**，使用 .NET Framework 桌面运行环境。当前版本在 .NET Framework 4.8.1 环境构建与验证。

1. 获取 **`日序-完整安装包.exe`**，双击运行。源码构建生成的安装器名为 `Daynest-Setup.exe`。
2. 根据需要勾选「登录 Windows 后自动启动」「创建桌面快捷方式」。
3. 安装后，从桌面或开始菜单打开 **日序**。

安装器内置程序、图标和背景图片，无需单独携带图片文件。程序安装到当前用户目录，通常不需要管理员权限。

首次启动使用内置背景及默认外观；覆盖安装会保留原有计划、子任务和外观设置。安装包不包含个人计划数据。

也可以直接运行 `Daynest.exe`。若使用直接运行方式，请先将程序放到固定目录，再开启自启，避免移动后启动路径失效。

## 快速上手

1. 点击底部 **「写下一个计划」**，选择类别并填写内容。
2. 有截止日期的事情选择「截止期限」；只想安排到某一天的事情选择「今日必做」。
3. 需要拆解时，在任务下方添加子任务。
4. 完成后勾选；暂时不再展示的任务可以归档。
5. 点击左下角的完成 / 归档记录，可以查看或恢复任务。

长期或截止任务旁的「＋」可以把它加入今日必做。这是同一条任务的执行引用，不会复制出另一份；完成状态会同步。

当天未完成的任务不会被自动勾选或自动移到第二天。可通过待处理入口继续今天、改期或转为长期计划。

### 窗口与快捷键

| 操作 | 方式 |
| --- | --- |
| 显示 / 隐藏 | `Ctrl + Alt + Shift + D`，或点击托盘图标 |
| 添加计划 | 窗口内按 `Ctrl + N` |
| 撤销最近一次计划修改 | 窗口内按 `Ctrl + Z` |
| 隐藏主窗口 | `Esc` 或顶部减号按钮 |
| 完整日历 / 小条切换 | 顶部细条图标 / 小条右侧展开图标 |
| 开关自启、置顶、锁定位置 | 偏好设置 |
| 彻底退出 | 托盘菜单 → 退出日序 |

关闭主窗口会将其收进托盘。若全局快捷键被其他软件占用，可使用托盘操作。

### 提醒说明

- 今日必做需要填写开始时间，才能设置到点或提前提醒。
- 截止任务支持日期或具体时间。只填日期时，截止点为当天结束，日期提醒在相应日期的 **09:00** 触发。
- 默认免打扰时段为 **22:00–08:00**，可以在设置中修改或关闭。
- 免打扰期间暂存提醒，结束后合并显示；禁用提醒期间的提醒会被跳过。
- 应用需要运行才能及时提醒。睡眠恢复或重新打开后，会检查最近 7 天内错过的提醒。

所有日期和时间使用本机时区。

## 数据与备份

计划保存在本机，不依赖账号或云端服务；当前不提供多设备自动同步。

| 内容 | 默认位置 |
| --- | --- |
| 程序 | `%LOCALAPPDATA%\Programs\Daynest` |
| 计划、设置和背景副本 | `%LOCALAPPDATA%\Daynest` |
| 独立自动备份 | `%USERPROFILE%\Documents\日序备份` |

修改后自动保存，保留最近 **100 份内容快照**和 **30 个备份日**。主文件缺失或异常时，会尝试从备份恢复；无法恢复时停止加载，避免静默覆盖原数据。

在 **设置 → 数据与备份** 中可以打开相关目录，或导出 / 导入 `.daynest` 备份。导出文件包含计划、子任务、设置和背景图片，可用于换电脑或手动备份。导入会替换当前内容，导入前会先保存一份原数据。

卸载保留计划数据。当前数据格式为 **v3**，支持导入旧 v1 / v2 备份；首次升级会保存 `before-v3-migration.json`。旧版程序不能读取新版数据。

## 从源码构建

项目采用 **C# + WPF + .NET Framework**。构建脚本调用 Windows 中的 .NET Framework 编译器及 WPF 程序集，不依赖 NuGet 包或现代 .NET SDK。

在源码根目录打开 PowerShell，运行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\Build.ps1
```

构建环境需具备脚本使用的编译器：

```text
%WINDIR%\Microsoft.NET\Framework64\v4.0.30319\csc.exe
```

默认输出到 `dist`：

```text
dist/
├── Daynest.exe          # 可直接运行的程序，内嵌背景
├── Daynest-Setup.exe    # 单文件安装器
└── Daynest.Tests.exe    # 行为测试程序
```

构建时必须保留源码目录中的 `default-background.png`、`daynest.ico` 和 `app.manifest`。

### 验证

在新的测试目录运行行为测试：

```powershell
.\dist\Daynest.Tests.exe .\test-results-local
```

测试覆盖三类计划、日期边界、提醒、子任务、归档统计、旧版迁移、备份恢复和保存冲突等场景。当前版本通过 **61 项行为测试**。

测试程序还会生成供界面检查使用的示例数据：

```powershell
.\dist\Daynest.exe --qa --data-dir .\test-results-local\ui-data --screenshots .\qa-shots-local
```

界面检查会操作并修改测试数据，**只使用独立测试目录**。该模式不注册自启、托盘或全局快捷键，也拒绝直接使用正式数据目录。
